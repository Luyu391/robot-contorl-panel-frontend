# ADR-002: 前端实现多层安全约束系统

## 背景

机械臂控制涉及物理运动，存在碰撞、超越物理限制等安全风险。传统方案依赖后端进行安全检查，但这种方式反馈延迟高，用户体验差。

## 决策

在前端实现三层安全约束系统，实时检测并阻止不安全操作。

### 技术方案

```typescript
// 第一层：基础角度限制
const JOINT_LIMITS_DEG = {
  base1: { min: -180, max: 180 },
  shoulder: { min: -130, max: 130 },
  // ...
};

// 第二层：安全模式收紧限制
const SAFE_JOINT_LIMITS = {
  shoulder: { min: -110, max: 110 },  // 比基础限制更严格
  // ...
};

// 第三层：关节间依赖规则
const INTER_JOINT_RULES = [
  {
    target: 'elbow2',
    dependsOn: 'elbow1',
    whenBelow: { threshold: -80, targetMin: -10 },
    whenAbove: { threshold: 80, targetMax: 10 },
  },
];
```

### 优点

1. **即时反馈**：前端约束可以实时阻止不安全操作，无需等待后端响应
2. **更好的用户体验**：用户在操作过程中就能感受到安全保护
3. **减轻后端负担**：后端只需进行最终校验

### 缺点

1. 前端安全约束可以被绕过（如直接调用 API）
2. 需要在前后端维护两套约束规则

## 结论

前端安全约束作为第一道防线，提供即时反馈；后端安全校验作为最终保障，确保数据安全。
