# Week 2 — 设计防穿模安全系统

> 工具：Trae AI 架构讨论，记录于 2026-06

## 我问

我的机械臂控制面板需要实现安全系统，防止机械臂在运动过程中发生碰撞或超出物理限制。我想到了三种方案：
1. 在后端实现所有安全检查
2. 在前端仅做角度限制
3. 在前端实现多层安全约束（基础限制 + 安全模式 + 关节依赖）

我应该如何选择？如果选第三种，如何设计关节间依赖规则？

## AI 答

推荐方案3，理由：
1. 前端安全检查可以提供即时反馈，改善用户体验
2. 关节间依赖规则是工业机械臂控制的标准做法
3. 多层约束可以适应不同场景（普通操作 vs 精密操作）

关节依赖规则设计示例：
```typescript
const INTER_JOINT_RULES = [
  {
    target: 'elbow2',
    dependsOn: 'elbow1',
    whenBelow: { threshold: -80, targetMin: -10 },
    whenAbove: { threshold: 80, targetMax: 10 },
  },
];
```

这表示：当 elbow1 角度 <= -80° 时，elbow2 的最小角度限制收紧到 -10°，防止两关节同时大幅弯曲导致自碰撞。

## 我后来做了什么

实现了三层安全系统：
1. 基础角度限制（JOINT_LIMITS_DEG）
2. 安全模式收紧限制（SAFE_JOINT_LIMITS）
3. 关节间依赖规则（INTER_JOINT_RULES）

同时添加了安全快照功能，用户可以保存当前安全姿态，必要时一键恢复。安全违规时会触发视觉警告（高亮红色）和回调通知。
